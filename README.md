# RCB IPL Strategy Analysis Using SQL

## Project Overview
A SQL-based IPL data analytics project focused on analyzing Royal Challengers Bengaluru (RCB) performance, evaluating player contributions, and supporting data-driven team selection and auction strategy.

## Project Objectives
- Analyze IPL match and player performance data.
- Evaluate batting and bowling contributions.
- Identify consistent performers.
- Support player selection using data-driven insights.
- Explore match outcomes and team performance patterns.

## Tools Used
- MySQL
- SQL queries
- Data analysis and aggregation
- Joins, CTEs and window functions (where applicable)

## Project Files
- **SQL Analysis:** `RCB_IPL_Strategy_Analysis.sql`
- **Presentation:** `RCB_IPL_Strategy_Analysis.pptx`
- **Project Documentation:** RCB IPL strategy analysis report.
